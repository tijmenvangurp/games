# Project Talent — Materialen 2025 per niveau

[← Project Talent](project-talent.md)

De PDF _Overzicht Verrijkingsmaterialen 2025_ markeert per materiaal de leerjaren. De vakkolommen (REK, TAAL, WO, TECH, LEER, DENK) zijn in de tekstlaag van de PDF niet gevuld; alleen de leerjaarmatrix is als tekst gemarkeerd. Deze tabel geeft daarom alleen de niveau-indeling.

## Dekking per niveau

| Niveau | Materialen |
| ------ | ---------: |
| K1     |          8 |
| K2     |         20 |
| K3     |         24 |
| L1     |         51 |
| L2     |         60 |
| L3     |         72 |
| L4     |         72 |
| L5     |         78 |
| L6     |         79 |
| S1/2   |         11 |
| S3/4   |          8 |
| S5/6   |          6 |

De lijst is het sterkst gevuld voor **L2–L6** (ruwweg groep 4–8) en veel minder voor **K1** en het secundair onderwijs. K1–K3 zijn kleuterniveaus, L1–L6 is lager onderwijs en S1/2–S5/6 is secundair; de koppeling aan Nederlandse groepen is indicatief.

Een materiaal telt mee in elk niveau waarvoor de PDF een markering heeft. Zes materialen hebben geen niveau-markering en staan in de tabel op `—`.
