# Domain Docs

Zo lezen de skills de domeindocumentatie van deze repo.

## Voor het verkennen

- `GLOSSARY.md` in de root.
- `docs/adr/`: lees de ADR's die het gebied raken.

Ontbreekt een bestand, ga dan stil verder. `domain-modeling` maakt het later
aan als termen of beslissingen echt nodig zijn.

## Structuur

Deze repo is single-context:

```text
/
├── GLOSSARY.md
├── docs/adr/
└── libs/
```

Gebruik de termen uit `GLOSSARY.md` in issue-titels, specs, tests en
voorstellen. Wijkt een voorstel af van een ADR, benoem dat expliciet.
