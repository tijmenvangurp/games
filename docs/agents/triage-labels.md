# Triage-labels

De skills gebruiken vijf canonieke rollen. Deze repo gebruikt dezelfde namen.

| Rol             | Label             | Betekenis                                       |
| --------------- | ----------------- | ----------------------------------------------- |
| needs-triage    | `needs-triage`    | Maintainer moet dit nog beoordelen.             |
| needs-info      | `needs-info`      | Wacht op informatie van de melder.              |
| ready-for-agent | `ready-for-agent` | Volledig gespecificeerd; een agent kan starten. |
| ready-for-human | `ready-for-human` | Vereist menselijke implementatie.               |
| wontfix         | `wontfix`         | Wordt niet opgepakt.                            |
